# Generador de direcciones residenciales

Página web sencilla que genera direcciones reales de casas en Estados Unidos y Canadá.

- Fuente de datos: [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), vía [Photon](https://photon.komoot.io) y [Nominatim](https://nominatim.org).
- Solo edificios de vivienda (casa, dúplex, casa en hilera, edificio residencial); se descartan comercios, bodegas y oficinas.
- Cada dirección trae enlaces para verificarla en Google Maps y Street View.

Uso: abrir `index.html` o la versión publicada en GitHub Pages.
